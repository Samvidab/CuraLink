# CuraLink — Developer Configuration

## Environment setup

```bash
cp .env.example .env          # secrets stay server-side; .env is git-ignored
./run_demo.sh                 # API :8000 + web :8443 (reuses healthy servers; never resets data)
./run_demo.sh status | stop   # stop only affects processes the script started
./run_demo.sh reset           # wipe fictional demo data (asks first)
./run_demo.sh e2e             # browser tests on an ISOLATED stack (:8011/:8454, separate DB)
```

Requirements: [uv](https://docs.astral.sh/uv/) (Python 3.11) and Node.js 22+.

## File structure

```
backend/app/
  config.py              env-driven settings (secrets, modes, clinic profile, term)        ← most CURALINK_CONFIG env markers
  curalink_config.py     non-secret config objects (exam fields, certificate wording, templates, placement)
  routers/               auth, student, scheduling, intake, voice, vision, absence, clinician, system
  services/
    ics_import.py, calendar_service.py   UniTime .ics import (CALENDAR_IMPORT)
    instructor_directory.py              contact lookup chain (COURSE_CATALOG_SOURCE, UNIVERSITY_DIRECTORY)
    intake_fields.py, intake_service.py  intake fields (INTAKE_FIELDS) + orchestration
    llm_gateway.py                       the ONLY module that calls Claude (text + vision)
    cartesia.py, voice_session.py        Cartesia STT/TTS + barge-in turn manager
    vision.py                            photo validation + non-diagnostic observations
    absence_mapper.py                    deterministic class-impact engine
    absence_service.py                   certificate versions, signing policy, outbox gates
    pdf_builder.py                       certificate template
    signature_vault.py                   AES-GCM signature storage
frontend/src/            React (Figma design): pages/student, pages/clinician, components, lib
sample_data/             fictional ICS, catalog, users, slots, synthetic demo images
docs/                    PRD, TRD, App Flow, Implementation Plan, this file, MANUAL_SETUP_CHECKLIST.md
scripts/config_index.py  regenerates the marker index below
```

## API integrations

| Integration | Module | Without credentials |
|---|---|---|
| Anthropic Claude (official `anthropic` SDK, `claude-opus-5-5`) | `services/llm_gateway.py` | scripted assistant, labelled |
| Claude vision (photo observations) | `services/llm_gateway.py::describe_image`, `services/vision.py` | colour analysis, labelled “not a medical model” |
| Cartesia STT `ink-whisper` + TTS `sonic-3.6` (WebSocket, `cartesia_version=2026-08-14`) | `services/cartesia.py`, `routers/voice.py` | browser speech, labelled fallback |
| University directory | `services/instructor_directory.py` | disabled |
| Email delivery | `services/absence_service.py::transport` | test inbox only (`/demo/inbox`) |

## Required vs optional credentials

- **None are required** to run the demo end to end.
- **Optional for the live demo:** `ANTHROPIC_API_KEY`, `CARTESIA_API_KEY` (+ `CARTESIA_VOICE_ID`).
- **Production-only:** see section D of [MANUAL_SETUP_CHECKLIST.md](MANUAL_SETUP_CHECKLIST.md).

## Troubleshooting

- **Port already in use:** run `./run_demo.sh status`. A healthy CuraLink is reused. Otherwise use `API_PORT=8001 WEB_PORT=8444 ./run_demo.sh`.
- **Assistant says “Scripted assistant (demo)” with a key set:** restart the API (keys are read at startup) and check `.run/8000/api.log` for `LLM_FALLBACK`.
- **Voice says “Browser speech · fallback”:** `CARTESIA_API_KEY` isn't set, or the API wasn't restarted. For mic errors, allow the microphone in the browser's site settings. `localhost` counts as a secure context.
- **Old database after an upgrade:** new columns are added automatically at startup, and existing data is kept.
- **“Delivery mode … is not implemented”:** `EMAIL_DELIVERY_MODE` must be `test_inbox`.
- **`SIGNATURE_KEY_INVALID`:** `SIGNATURE_ENCRYPTION_KEY` must decode to 32 bytes.
